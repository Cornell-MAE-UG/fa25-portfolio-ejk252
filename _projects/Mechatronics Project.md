As part of a class project, we were tasked to design a robot using an Arduino. At the end of the semester, there was a class wide tournament-style competition where robots dueled on a board to capture more cubes than their opponent in 1 minute. 

On my team, my main job was as the coder. I wrote the majority of the code for the robot. This involved using our robot's color sensor to measure and react to detected either the black border, or a color change between the yellow and blue sides.
